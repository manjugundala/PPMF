# Roadmap

| Monitor | Goal | Status |
|---|---|---|
| Detect broken connections | Find broken connections and their affected apps and flows | ✅ Released 1.0 |
| Environment inventory + configuration app | Discover environments; admin settings | ✅ Released 1.0 |
| Application user credential expiration | Warn before app-registration secrets and certificates expire | Planned |
| Service account password expiration | Warn before service-account passwords expire | Planned |
| Production flow failures | Daily digest of failed runs in production environments | Planned |
| Solution deletion events | Alert when a solution is deleted | Planned |
| Logger child flow | Fix column mapping so any flow or app can log with one call | Planned |
| Email templates | Move email content to `PPMF \| Email Templates` | Planned |
| Power BI dashboard | Trends from `PPMF \| Logs` | Planned |

Ideas and requests: open an [issue](https://github.com/manjugundala/PPMF/issues).
